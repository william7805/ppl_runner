# 0005. npm comme gestionnaire de paquets

- Date : 2026-10-16
- Statut : Accepté

## Contexte

Il faut un gestionnaire de paquets unique pour installer les
dépendances de façon identique sur mon PC, dans la CI et dans l'image
Docker.

## Décision

J'utilise npm, fourni avec Node.js.

- Aucun outil supplémentaire à installer, nulle part.
- Le `package-lock.json` est commité : il fige la version exacte de
  chaque paquet et son empreinte d'intégrité.
- La CI et le Dockerfile utilisent `npm ci`, qui installe exactement
  le contenu du lock.

## Alternatives écartées

- **pnpm** : plus rapide et plus strict sur les dépendances, mais un
  outil de plus à installer et configurer partout.
- **yarn** : aucun avantage décisif pour ce projet.

## Conséquences

- Positif : installations reproductibles sur toutes les machines.
- Négatif : installations plus lentes et `node_modules` plus lourd
  qu'avec pnpm.
- Règle : ne jamais mélanger les gestionnaires, un seul fichier de
  lock dans le dépôt.
